LozCharts

Gráficos SVG interactivos, accesibles y sin dependencias. Pasa el puntero o usa las flechas del teclado sobre cada gráfico; pulsa la leyenda para ocultar series.

Tema
LozBarLozLine

Barras, líneas y áreas

Apiladas y agrupadas, con valores negativos, en tiempo continuo y en porcentaje.

Small multiples

Muchos gráficos pequeños con la misma escala: se comparan formas de un vistazo, sin enredar líneas.

Dos medidas con distintas unidades

El doble eje, con salvaguardas, y dos alternativas que no dependen de dónde se ponga cada eje.

Dispersión, rangos y precios

Barras horizontales, puntos y burbujas, bandas, escalones y velas.

Proporciones, radares y embudos

Partes de un todo, un indicador contra su meta, perfiles en varias dimensiones y pasos de un proceso.

Cómo se usa

Abre este archivo con doble clic: carga dist/lozcharts.umd.js y expone window.LozChart. En proyectos con Vite, React o Angular usa import { LozChart } from 'lozcharts'. 

<div id="grafico"></div>
<script src="lozcharts.umd.js"></script>
<script>
  const chart = new LozChart('#grafico', {
    title: 'Ventas por mes',
    data: ventas,
    xAxis: { field: 'mes', type: 'time' },
    yAxis: { format: 'currency' },
    series: [
      { type: 'bar',  field: 'online', name: 'Online', stack: true },
      { type: 'bar',  field: 'tienda', name: 'Tienda', stack: true },
      { type: 'line', field: 'meta',   name: 'Meta', smooth: true },
    ],
  });
  chart.setData(nuevosDatos); // anima del estado anterior al nuevo
</script>
