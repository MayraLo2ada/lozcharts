Lo que puedes escribir

        

          

            
Marcas

            

              
cell

              
Una celda de una tabla: x e y son categorías.

              
text

              
Un texto: "text": "{valor} %".

              
icon

              
Un ícono propio, un emoji, un path o una image.

              
point

              
Un círculo; size fijo o desde un campo.

              
bar

              
Una barra desde el cero (o desde y2).

              
line

              
Una línea por cada group; "curve": "smooth".

              
rule

              
Una línea de referencia: "y": 60 con su label.

              
link

              
Los enlaces de una red (network).

            

          

          

            
Canales

            

              
x, y, size

              
Un campo o una cuenta: "valor - meta". Fijo: { "value": "Meta" }.

              
lon, lat

              
En un mapa, con "geo": { "map": "mundo" }.

              
text, title, alt

              
Plantillas: lo que va entre llaves se calcula.

              
color, icon

              
Un valor, una tabla { "field", "map" } o una condición.

              
filter

              
Solo las filas que cumplen: "estado == 'falla'".

              
tooltip

              
false, o la lista de campos que quieres ver.

            

          

          

            
Condiciones y colores

            
"icon": {
  "if": "valor >= meta",
  "then": "smile",
  "else": "sad"
}
"color": {
  "field": "valor",
  "scale": "semaforo",
  "by": "row"
}

            

              Se compara con == != < <= > >=, se junta con and, or y
              not, y hay abs, round, min, max,
              contains. Colores: good
              warn bad, la paleta (violet,
              pink…) o un #hex. by compara por fila, por columna o con todo;
              thresholds pone cortes fijos.
