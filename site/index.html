Gráficos que se entienden a la primera.

LozCharts es una librería de gráficos en SVG, accesible y sin dependencias. Diecinueve tipos, zoom, mapas, y componentes para React, Angular y Django con HTMX.

Cien mil puntos, sin esperar.

Solo se dibuja lo que se ve: por cada columna de píxeles, el primero, el mínimo, el máximo y el último. El trazo es el mismo y ningún pico se pierde. Pruébalo y mira el tiempo.

Colores que se distinguen siempre.

La paleta Coral está validada para daltonismo: los colores que más se usan juntos se distinguen también para quien no ve el rojo y el verde. Míralo con sus ojos.

Se escuchan, no solo se ven.

Cada gráfico se describe a los lectores de pantalla, trae su tabla de datos y se recorre con el teclado. Haz clic en el gráfico y usa las flechas.

Funciona donde ya trabajas.

<script src="lozcharts.umd.js"></script>
<div id="ventas"></div>
<script>
  new LozChart('#ventas', {
    data: [{ mes: '2026-01', ventas: 42000 }, { mes: '2026-02', ventas: 45500 }],
    xAxis: { field: 'mes', type: 'time' },
    series: [{ type: 'bar', field: 'ventas', name: 'Ventas' }],
  });
</script>
import { Chart } from 'lozcharts/react';

export function Ventas({ filas }) {
  return (
    <Chart
      title="Ventas"
      data={filas}
      xAxis={{ field: 'mes', type: 'time' }}
      series={[{ type: 'bar', field: 'ventas', name: 'Ventas' }]}
      zoom
    />
  );
}
// Un elemento HTML estándar: sirve en Angular, Vue, Svelte o sin framework.
import 'lozcharts/element';

// Angular: schemas: [CUSTOM_ELEMENTS_SCHEMA]
<loz-chart [options]="opciones" (lozzoom)="alHacerZoom($event)"></loz-chart>

// Vue
<loz-chart :options="opciones" @lozhover="marcar" />
{# La vista arma las opciones en Python; json_script las escapa. #}
<div data-lozchart="#opciones"></div>
{{ opciones|json_script:"opciones" }}

<script>
  htmx.onLoad((el) => LozChart.initAll(el));
  document.body.addEventListener('htmx:beforeSwap', (e) => LozChart.destroyAll(e.detail.target));
</script>
