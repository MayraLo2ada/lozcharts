Así se dibuja un gráfico.

LozCharts es una librería de gráficos en SVG, escrita en TypeScript y sin dependencias. Diecinueve tipos, accesibles desde el primero, gratis también para empresas.

Estas son sus láminas de diseño: gráficos reales con las cotas a la vista.

Las notas a mano las mide la página sobre el gráfico. Cambia el ancho de la ventana y se recalculan.

Una curva suave que no miente.

Una curva bonita puede pasarse de los datos: entre un 10 y un 50 dibuja un 52 que no existe. La línea suave de LozCharts usa el método de Fritsch y Carlson, y nunca sale del rango entre dos puntos.

  1. Calcula la pendiente de cada tramo.
  2. En cada punto, la tangente es el promedio de las dos vecinas. Si cambian de signo, hay un pico: la tangente es cero y el punto queda plano.
  3. Si una tangente es muy empinada para su tramo, la recorta.
si d₍ᵢ₋₁₎ · dᵢ ≤ 0 entonces mᵢ = 0
si α² + β² > 9 entonces τ = 3 / √(α² + β²)

Cien mil puntos en lo que mide un píxel.

Si caben más de dos datos por columna de píxeles, LozCharts guarda solo cuatro de cada columna: el primero, el mínimo, el máximo y el último. La línea se ve igual y ningún pico se pierde. Estas medidas son de tu navegador, ahora mismo.

Montaje

  1. Instálala desde GitHub. Todavía no está en npm. 
    npm install github:MayraLo2ada/lozcharts
  2. Crea el gráfico. Con <script> o con import: 
    new LozChart('#grafico', {
  data: ventas,
  xAxis: { field: 'mes', type: 'time' },
  series: [{ type: 'line', field: 'online', smooth: true }],
});
  3. En React, lozcharts/react. En Angular, Vue o Svelte, el elemento: 
    <loz-chart options='{"data": [...], ...}'></loz-chart>
  4. Con Django y HTMX, las opciones van en un atributo: 
    <div data-lozchart="#opciones-ventas"></div>

Normas que cumple

  • Se describe a los lectores de pantalla y trae su tabla de datos.
  • Se recorre con el teclado: flechas, Inicio, Fin y Escape.
  • Respeta a quien pide menos movimiento.
  • Exporta PNG, SVG y CSV.
  • Paleta Coral, validada para daltonismo, con tonos propios para el modo oscuro.
