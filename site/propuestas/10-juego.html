    Llévate lo que armaste.

    Todavía no está en npm. Se instala desde GitHub y funciona igual.

    1. Instálala

      Desde GitHub, o copia el archivo UMD si no usas empaquetador.

      npm install github:MayraLo2ada/lozcharts

    2. Elige cómo

      Script, import, React, <loz-chart> para Angular, Vue o Svelte, o Django con HTMX.

      import { LozChart } from 'lozcharts';

    3. Pega tu código

      El de arriba ya es válido. Cambia los datos por los tuyos.

      new LozChart('#grafico', { … });
