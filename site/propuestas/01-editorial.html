Diecinueve formas de contar algo

Cada dato tiene su forma. Aquí van ocho de las diecinueve, con los mismos datos de la galería.

Una barra compara. Una línea cuenta lo que pasó en el tiempo. Un sankey dice de dónde vino la gente y a dónde se fue. LozCharts trae diecinueve tipos y todos se comportan igual: el mismo tooltip, la misma leyenda, el mismo teclado, la misma paleta.

Velas y OHLC para precios. Mapa de calor para días y horas. Treemap cuando las categorías son muchas. Mapas del mundo, coloreados o con burbujas. Y small multiples cuando cinco líneas en un mismo gráfico ya se enredan.

Diecinueve tipos, un solo comportamiento.

Lo que tardó tu navegador en dibujar el gráfico de abajo.

El gráfico de abajo tiene 100 000 puntos. LozCharts solo dibuja lo que se ve y, en cada columna de píxeles, guarda el primero, el mínimo, el máximo y el último. El trazo queda igual y ningún pico se pierde.

    Cinco maneras de invitarla a tu proyecto

    Funciona en lo que ya usas. Sin adaptadores raros ni otra librería detrás.

    Con un script

    Sin servidor y sin build. Abres el archivo y listo.

    <script src="lozcharts.umd.js"></script>
<script>
  new LozChart('#grafico', {
    data: ventas,
    xAxis: { field: 'mes', type: 'time' },
    series: [{ type: 'bar', field: 'online', name: 'Online' }],
  });
</script>

    Con import

    Vite, webpack o Node.

    import { LozChart } from 'lozcharts';
const chart = new LozChart(el, opciones);
chart.destroy();

    En React

    Las opciones van como props.

    import { Chart } from 'lozcharts/react';

<Chart data={data} series={series} zoom />

    En Angular, Vue o Svelte

    Un elemento HTML estándar.

    <loz-chart [options]="opciones">
</loz-chart>

    Con Django y HTMX

    Opciones en JSON y listo en cada swap.

    <div data-lozchart="#opciones"></div>
{{ opciones|json_script:"opciones" }}
htmx.onLoad((el) => LozChart.initAll(el));

    Colofón

    LozCharts está escrita en TypeScript, sin dependencias, por Mayra Lozada. Exporta a PNG, SVG y CSV, y tiene modo oscuro propio. Licencia MIT: gratis, también para empresas. Todavía no está en npm; por ahora se instala desde GitHub.
